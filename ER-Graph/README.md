# Erdos Reyni Graph Generator

## Generates graph1, graph2, test_pairs, anchor_links files. You need to add config.txt to the directory
## Usage

```bash
python gen.py <number_of_nodes> <avg_degree> <output_directory> <num_anchor_edges>
```

Example:

```bash
python gen.py 10000 10 /scratch/.../g10k 5000
```
